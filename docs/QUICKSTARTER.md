# Quickstarter — Get Going in 5 Minutes

Get the curriculum app running and see the main idea in under 5 minutes.

---

## 1. Run the app (2 min)

```bash
cd curriculum-app
npm install
npm run dev
```

Open **http://localhost:3000**.

---

## 2. See the big idea (2 min)

- **Problem:** 100k+ AI skills and MCP tools exist—too many to load into the AI. That’s the “paradox of choice.”
- **Solution:** Teach the AI **how to find** the right tool (SP Search), then use a **3-step protocol**: analyze → get access → let AI build.
- **Result:** You become the **conductor** (directing AI) instead of the **miner** (doing everything yourself)—“Productivity Singularity.”

That’s what the curriculum teaches.

---

## 3. Use the app (1 min)

- **Nav:** Click category names to jump (e.g. “2. SP Search”, “7. Solo Entrepreneur”).
- **Tables:** Each section has steps with Concept, Video timestamp, Explanation, and Research.
- **Checklist:** Scroll to **“Full step list”** at the bottom for one ordered list of all 23 steps.

---

## 4. Your first action

Pick one:

- **A)** Watch the reference video at **01:28** (paradox of choice + SP Search goal).  
- **B)** Read **Category 7** and write down the 5 Solo Entrepreneur actions.  
- **C)** In the app, find **Step 19** and do it (configure search & MCP).
